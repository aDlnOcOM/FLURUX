# FLURUX 0.3.5 для Windows x64

**Отдельная вкладка zapret2** объединяет установку, списки сайтов, параметры и управление сеансом. В режиме «Только zapret2» приложения подключаются к сайтам напрямую через системный маршрут. FLURUX запускает winws2 с WinDivert. Tor, SOCKS5 и сервер для этого режима не нужны.

1. Откройте **FLURUX-0.3.5-Setup-x64.exe**. Для установленной версии 0.3.4 выберите **Обновить и восстановить**.
2. Откройте **zapret2 → Движок → Установить движок** и подтвердите запрос Windows. Для автономной установки выберите **Из ZIP…**. На этой странице есть ссылка на ZIP подходящей версии.
3. На странице **Маршрут** добавьте домены сайтов и выберите стратегию. Нажмите **Запустить zapret2**. Для проверки введите адрес или оставьте поле пустым, чтобы проверить первый сайт списка.

## Управление

- 60 профилей объединяют четыре варианта обработки TLS/QUIC, три варианта IP и пять наборов портов. Выберите строку на странице **zapret2 → Каталог** и нажмите **Выбрать профиль**. Свои списки портов можно задать вручную.
- На вкладке **Порты и исключения** можно задать порты назначения и домены, которые нужно пропустить. Импорт TXT объединяет сайты с текущим списком. Экспорт сохраняет список в UTF-8.
- **Сохранить** записывает параметры. **Перезапустить** применяет новые настройки к самостоятельному сеансу. **Остановить** завершает его. Кнопка **Журнал** открывает сообщения о запуске и результатах проверок.
- На странице **Движок** доступны проверка файлов, восстановление и удаление. Настройки и домены сохраняются после удаления движка. Сама установка драйвера при первом запуске требует разрешения Windows.
- HTTPS-загрузка и импорт ZIP сверяют семь файлов с манифестом релиза. Помощник повторно проверяет SHA-256 защищённых копий перед их использованием. Поддерживаемая сборка — [zapret-win-bundle на коммите 6b4375fa](https://github.com/bol-van/zapret-win-bundle/tree/6b4375fa04f6bd7017eec379e16e462d3ea8df66).

На вкладке **Тесты** доступны проверка выбранного профиля или текущего подключения, сравнение 60 профилей и глобальный тест настроенных маршрутов. В сводке видны тип пинга, доступность WEB, скорость VIDEO, оценка GAME и причины пропусков. Строки можно сохранить в CSV. Откройте F1 на вкладке тестов для расшифровки. Подробности о границах измерений приведены в отдельном файле **zapret2-measurements.ru.md**. Контрольная сумма установщика находится в **SHA256SUMS.txt**.
