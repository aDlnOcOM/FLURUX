# FLURUX 0.3.2 для Windows x64

Скачайте и откройте **FLURUX-0.3.2-Setup-x64.exe**. Подтвердите установку или обновление. FLURUX откроется автоматически. Для следующего запуска выберите **Пуск → FLURUX**.

## Что исправлено

- В окне 800×590 на вкладке «Каскады» доступны кнопки подключения и остановки, строка состояния и справка. Длинные формы прокручиваются колесом, полосой прокрутки и при переходе между полями клавишей Tab.
- При нажатии «Остановить» во время первой загрузки Tor сразу появляется надпись «Отмена загрузки…». Повторное нажатие блокируется. Запоздавший ответ загрузчика не запускает Tor.
- Закрытие окна во время проверки сайта отменяет запрос и завершает процесс curl. При ошибке в номере порта SOCKS5 приложение показывает допустимый диапазон до загрузки Tor.
- Смена стратегии сразу открывает её форму. При несохранённых правках можно отменить переход. Во время подключения параметры работающего каскада защищены от случайного редактирования.
- На вкладке Mesh результат операции виден рядом со списком узлов. При обновлении списка сохраняется выделенный узел. Кнопка «Выбрать выход» доступна для узлов в сети, объявивших себя выходом.

Python и Tk входят в установщик. Для первого подключения через Tor приложение предложит скачать официальный комплект. Для каскадов укажите движок и реквизиты выбранной стратегии. Установщик без подписи Authenticode. Контрольная сумма файла приведена в **SHA256SUMS.txt**.
