# FLURUX 0.3.0 — защита ключей и маршрутов

FLURUX для Windows объединяет Tor и его мосты, zapret2, SSH, прокси, VPN-каскады и Mesh через Tailscale в одном графическом интерфейсе. В этом выпуске изменились запуск привилегированных компонентов, хранение конфигураций и настройка собственных серверов.

### Что изменилось

- zapret2 запускает отдельный помощник из Program Files. Перед запуском он проверяет владельца, права и хеши семи файлов, включая DLL, драйвер и Lua. Список доменов передаётся напрямую. Для системного TUN добавлена опциональная блокировка исходящих соединений средствами Windows Filtering Platform для IPv4 и IPv6.
- Профили и строки мостов защищены пользовательским DPAPI. Временные файлы доступны владельцу сеанса и SYSTEM. FLURUX распознаёт незавершённые сеансы по блокировке файла. Клиенты sing-box и MASQUE CONNECT-UDP получают рабочую конфигурацию через стандартный ввод.
- На управляемых Linux-узлах службы sing-box, Xray, MASQUE CONNECT-UDP и dnsdist используют отдельные учётные записи systemd. Синхронизация читает публичные данные по SSH без sudo. Разбор REALITY отклоняет повреждённый файл ключей. В профиле WireGuard с пересылкой на шлюзе у двух связей разные пары ключей.
- Для внешних HTTP/SOCKS5 с паролем требуется явное разрешение. У OpenVPN через HTTP CONNECT можно выбрать HTTPS до входа. Для собственного фиксированного TCP/UDP-ретранслятора задаётся разрешённая сеть клиентов. Клиентские конфигурации sing-box используют DoH для начального определения адреса узла.
- Встроенная справка содержит 39 статей и контекстную помощь по 26 профилям.

### Файлы

| Файл | Назначение |
| --- | --- |
| FLURUX-0.3.0-Windows-x64.zip | Переносимое приложение, исходный код и руководство. Распакуйте и откройте Start.cmd. Требуется Python 3.12+ с Tk. |
| FLURUX-Security-x64.msi | Системная установка приложения и помощника. Нужна для zapret2, сетевой блокировки и запуска системного VPN через установленный Start-Admin.cmd. |
| SHA256SUMS.txt | Контрольные суммы SHA-256 для ZIP и MSI. Пакет MSI выпускается без подписи Authenticode. |

Сетевые движки устанавливаются отдельно. Для zapret2 подготовьте официальный комплект скриптом Prepare-Zapret.ps1 по инструкции в README. Установленный помощник сверяет файлы при каждом запуске.

### Переход с 0.2

1. Если использовались строки мостов, запустите новую переносимую версию рядом с прежним каталогом data для миграции в DPAPI.
2. Для собственных узлов повторите «Настроить узлы по SSH». Это обновит службы, опубликует открытые данные для синхронизации и создаст отдельный ключ связи шлюз–выход.
3. Для системной блокировки укажите IP входного узла, а имя сертификата задайте отдельно. После остановки туннеля ограничения сохраняются. Для восстановления доступа нажмите «Каскады → Снять блокировку сети». Сделайте это перед удалением MSI.

### Проверка выпуска

На Windows прошли модульные тесты, проверка типов, графический тест 26 профилей, локальные проверки DoH/DoT и соединений через TLS, прокси и каскады. Проверены отказ при неверном CA, имени сервера и пароле, отказ нового соединения после остановки входного узла и согласование TLS 1.3 для MASQUE CONNECT-UDP. Применение правил WFP и драйвера WinDivert на рабочей системе, работа с внешним tailnet и развёртывание служб на реальном Linux-сервере остаются непроверенными.
