# FLURUX 0.3.1 для Windows x64

Скачайте **FLURUX-0.3.1-Setup-x64.exe**, откройте его и подтвердите установку. FLURUX запустится и добавит ярлык в меню «Пуск». Python, Tk и системный помощник входят в комплект. Поддерживаются Windows 10 и 11 x64.

**Первое подключение.** Нажмите «Запустить» и подтвердите загрузку Tor с официального сервера (23 МБ). FLURUX проверяет SHA-256 архива и сохраняет движок на компьютере. Когда индикатор достигнет 100%, нажмите «Открыть Edge через Tor». Если прямое подключение недоступно, выберите «Настройки → Транспорт → Snowflake» и повторите подключение.

Установка приложения работает без интернета. Для первого получения Tor нужен доступ к Tor Project. Остальные движки, включая комплект zapret2, подключаются отдельно. Для системного VPN используйте «Запуск от имени администратора» у установленного FLURUX.

Выпуск содержит установщик EXE и файл SHA256SUMS.txt с его контрольной суммой. У установщика нет подписи Authenticode, поэтому Windows может показать предупреждение SmartScreen.
