# FLURUX 0.3.3 для Windows x64

Откройте **FLURUX-0.3.3-Setup-x64.exe**. Для первой установки оставьте стандартный путь или выберите папку через «Обзор…». Путь можно ввести вручную. FLURUX создаёт ярлыки на рабочем столе и в списке приложений меню «Пуск».

## Обслуживание

- Если FLURUX уже установлен, этот же EXE показывает его версию и расположение. Кнопка **Обновить и восстановить** устанавливает 0.3.3 поверх предыдущей версии.
- **Восстановить** перезаписывает файлы программы из комплекта и создаёт оба ярлыка заново. Подходит, если повреждён файл, пропал ярлык или приложение перестало запускаться.
- **Удалить…** запрашивает подтверждение и удаляет приложение и ярлыки. Настройки и профили сохраняются. Чтобы выбрать другой путь для установленной копии, удалите её и снова откройте установщик.
- Основное приложение и встроенный Python размещаются в выбранной папке. Помощник для привилегированных операций располагается в `%ProgramFiles%\FLURUX\Security`.

## Переключение вкладок

После перехода в «Каскады» можно вернуться к другим вкладкам мышью или клавишами Ctrl+Tab. В окне **FLURUX · Системный VPN** разделы «Подключение», «Настройки» и Mesh предлагают открыть нужный раздел с обычными правами. Повышенное окно с работающим VPN остаётся открытым. Журнал и справка доступны в том же окне.

Для проверки загрузки используйте **SHA256SUMS.txt**. Установщик поставляется без подписи Authenticode.
