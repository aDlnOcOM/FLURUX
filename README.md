# FLURUX

Графическое приложение для Windows 10 и 11 x64. Управляет Tor, zapret2, профилями VPN и прокси, своими Linux-узлами по SSH и сетью Tailscale. Полное руководство встроено в приложение. Откройте **Справка**, используйте поиск или нажмите **F1** в нужном разделе.

## Установка одним файлом

Скачайте **FLURUX-0.3.3-Setup-x64.exe** из выпуска для Windows 10/11 x64. Оставьте предложенную папку, выберите родительский каталог через **Обзор…** или введите полный путь к новой либо пустой папке вручную. Нажмите **Установить**. После установки откройте FLURUX через **Пуск → Все приложения → FLURUX** или с рабочего стола. Python и Tk входят в комплект.

Повторный запуск того же EXE показывает установленную версию и её папку. **Восстановить** заново устанавливает программные файлы и оба ярлыка. Предыдущую версию можно обновить в её текущей папке. **Удалить…** запрашивает подтверждение и удаляет установленные файлы и ярлыки. Пользовательские настройки и профили сохраняются. Для переноса в другую папку удалите приложение через установщик, затем откройте его снова. Привилегированный помощник и его движки используют защищённый системный каталог `%ProgramFiles%\FLURUX`. Для запуска системного VPN выбирайте диск и каталоги, где другие пользователи не могут заменить папку установки.

Для первого подключения нажмите **Запустить** и подтвердите загрузку Tor (23 МБ). FLURUX скачает официальный архив, проверит SHA-256 и сохранит файлы для следующих подключений. Дождитесь 100% и нажмите **Открыть Edge через Tor**. Если прямой вход недоступен, откройте **Настройки → Транспорт → Snowflake** и подключитесь снова. Параметры уже настроенных профилей сохраняются. Установка EXE работает офлайн, получение Tor в первый раз требует доступа к сайту Tor Project. Остальные движки настраиваются в соответствующих профилях.

Для системного VPN нажмите правой кнопкой на установленный FLURUX и выберите «Запуск от имени администратора». Установщик включает помощник безопасности. При использовании zapret2 дополнительно подготовьте комплект по инструкции ниже. Для удаления приложения используйте **Параметры Windows → Приложения → FLURUX**. Перед удалением снимите сетевую блокировку, если она включена.

## Запуск из исходников

1. Распакуйте архив в доступную для записи папку и запустите `Start.cmd`. Требуется Python 3.12+ с Tkinter. Если вы используете uv, из папки приложения можно запустить `uv sync`, затем `uv run python run.pyw`. [Python для Windows](https://www.python.org/downloads/windows/)
2. Во вкладке **Настройки** укажите только нужные движки. Распакуйте официальные сборки целиком. Для zapret2 выполните установку из раздела «Компоненты Windows» ниже. Для Tor выберите `tor\tor.exe` из Tor Expert Bundle. [Сборка zapret](https://github.com/bol-van/zapret-win-bundle) · [Tor Expert Bundle](https://www.torproject.org/download/tor/)
3. Для zapret2 укажите домены, по одному на строку. Например, `example.org` охватывает и его поддомены. Для WebTunnel или obfs4 вставьте целые строки мостов. Для Snowflake можно оставить поле пустым, тогда приложение прочитает мосты из текущей сборки Tor. [Получение мостов](https://support.torproject.org/ru/tor-browser/circumvention/getting-bridges/)
4. Во вкладке **Подключение** выберите режим и нажмите **Запустить**. Для zapret2 Windows покажет запрос UAC. Для Tor дождитесь 100%. Чтобы проверить конкретный сайт, введите его адрес и выберите **Без SOCKS5** или **Через Tor**. Кнопка **Подтвердить выход Tor** обращается к сервису проверки Tor Project. [Tor Check](https://check.torproject.org/)

## Компоненты Windows

Для базового Tor и прокси запустите FLURUX с обычными правами. Помощник для zapret2 и сетевой блокировки входит в EXE. При использовании старой архивной сборки установите соответствующий **FLURUX-Security-x64.msi**. Помощник размещается в системном каталоге Program Files. Пакет собран без подписи Authenticode. Файл SHA256SUMS.txt в релизе содержит контрольные суммы архива и MSI.

**zapret2.** Скачайте ZIP исходного комплекта на закреплённом коммите, распакуйте его и укажите каталог с winws2.exe. Выполните подготовку с обычными правами в папке распакованного FLURUX. Каталог назначения должен быть новым. [Комплект zapret для этого выпуска](https://github.com/bol-van/zapret-win-bundle/tree/6b4375fa04f6bd7017eec379e16e462d3ea8df66)

```powershell
.\security\Prepare-Zapret.ps1 -Bundle "C:\Downloads\zapret-winws" -Destination "$env:TEMP\flurux-export\engine"
```

Скопируйте созданную папку **engine** через Проводник в `C:\Program Files\FLURUX\Security`. Используйте копирование, чтобы новые файлы унаследовали права целевой папки. Если владельцем скопированных файлов значится персональная учётная запись, администратор должен установить владельцем встроенную группу администраторов. В повышенной консоли можно выполнить `icacls "C:\Program Files\FLURUX\Security\engine" /setowner *S-1-5-32-544 /T`. Помощник проверяет состав каталога и SHA-256 семи файлов при каждом запуске. Загруженные компоненты zapret2 сохраняют лицензии своих разработчиков.

**Системный TUN.** Пользователи EXE уже получили встроенный интерпретатор. При использовании старого MSI установите системный Python 3.12–3.14 с Tk в стандартный каталог Program Files. Скопируйте полную распакованную сборку sing-box 1.14.4 x64 в `C:\Program Files\FLURUX\engines\sing-box`, а сборку 1.15.0-alpha.13 для CONNECT-IP в `engines\sing-box-preview`. Требования к владельцу и правам те же. Запустите установленный **Start-Admin.cmd** от администратора. В окне администратора доступны системные VPN, журнал и справка. Вкладки «Подключение», «Настройки» и Mesh открываются и предлагают перейти в обычное окно выбранного раздела. При этом запущенный системный VPN продолжает работать. При первом запуске администратор видит доступные профили текущей учётной записи. Его копии сохраняются отдельно. Для внешних движков в обычном режиме укажите путь в профиле. Для sing-box и Xray 26.11.9 проверяются закреплённые хеши EXE и DLL. Для Tor и lyrebird закреплён Tor Expert Bundle 16.0.1 x64. Для остальных выбранных движков проверяется Authenticode. В профилях с полем SHA-256 можно указать контрольную сумму из доверенного источника.

**Блокировка сети.** В профиле sing-box включите «Системный TUN» и «Блокировать интернет вне TUN». Укажите числовой IP первого узла и отдельно имя TLS при необходимости. Пока блокировка включена, Windows разрешает связь движка с входным узлом, локальный loopback и трафик через активный интерфейс FLURUX. Завершение клиента закрывает временные разрешения. Основные правила сохраняются после отключения и перезагрузки. Для восстановления доступа используйте **Каскады → Снять блокировку сети**. Офлайн-команда для повышенной консоли PowerShell:

```powershell
& "$env:ProgramFiles\FLURUX\Security\FluruxGuard.exe" unlock
```

Снимите блокировку перед удалением MSI. Прокси SOCKS защищает трафик программ, направленных на локальный порт. Настройка сетевой блокировки относится к системному TUN.

**Обновление с 0.2.** При первом запуске переносимой копии прежний файл data/settings.json переходит на DPAPI, затем настройки копируются в профиль Windows. Для миграции запустите новую переносимую версию из папки со старым data. Повторите настройку своих узлов по SSH. Для WireGuard на шлюзе появится отдельная пара ключей, а для синхронизации сертификатов и публичных ключей — доступный без sudo файл. Установите CIDR клиентов для фиксированных ретрансляторов и собственных DNS. Старые временные папки версии 0.2 не имеют признака работающего сеанса. После закрытия старого клиента их можно проверить вручную. При подключении к внешнему HTTP/SOCKS5 пароль требует явного разрешения. Для OpenVPN через HTTP можно выбрать HTTPS на первом узле.

## Режимы

| Режим | Маршрут |
| --- | --- |
| zapret2 | Прямое соединение. `winws2` применяет выбранную стратегию к указанным доменам. |
| Tor | Локальный прокси для приложений. WebTunnel, obfs4, Snowflake или прямой вход в Tor. |
| zapret2 + Tor | Оба маршрута доступны параллельно. |
| WebTunnel через zapret2 | Сначала запускается `winws2`, затем Tor. TLS-имена мостов WebTunnel на порту 443 добавляются к списку zapret2. При остановке `winws2` каскад завершает Tor. |

В zapret2 доступны разделение TLS ClientHello, перестановка его сегментов и профиль TLS + QUIC. Кнопка проверки HTTP показывает код и время. Проверка из приложения использует `curl.exe`, поэтому для профиля QUIC дополнительно проверяйте нужный сайт в своём браузере. [Документация zapret2](https://github.com/bol-van/zapret2/blob/master/docs/readme.md)

Прокси Tor слушает `127.0.0.1`, по умолчанию порт `19050`. Для SOCKS-клиентов включите разрешение DNS через прокси, если настройка доступна. В Edge используется отдельный профиль с этим прокси. Для задач, требующих защиты от браузерного отпечатка, используйте Tor Browser. [Справка Tor Project](https://support.torproject.org/tor-browser/security/using-tb-safely/)

Настройки, включая строки мостов, хранятся под защитой пользовательского DPAPI в `%LOCALAPPDATA%\FLURUX\settings.json`. Эта же папка содержит кэш Tor и профиль Edge. Для диагностики откройте вкладку **Журнал**. Кнопка **Остановить** завершает процессы, запущенные приложением.

## Проверка проекта

```powershell
uv sync
uv run python -m unittest discover -s tests -v
ruff check . --fix
ruff format .
mypy src --strict
```

Ruff и mypy нужны только для разработки и ставятся как отдельные инструменты. Код приложения использует стандартную библиотеку Python.


## Каскады и свои узлы

Во вкладке **Каскады** выберите стратегию и заполните поля профиля. Кнопка **Новый профиль** создаёт ещё один профиль выбранной стратегии. На вкладке профиля укажите путь к движку Windows. Для готового прокси или VPN используйте выданные вам реквизиты. Для собственного сервера добавьте SSH-псевдоним, проверьте его host key в OpenSSH и нажмите **Настроить узлы по SSH**. Перед выполнением приложение покажет список узлов и ролей. Поддерживаются Debian/Ubuntu с systemd, Python 3.10+ и root либо sudo без запроса пароля. AmneziaWG устанавливается через PPA на Ubuntu.

Базовые профили используют sing-box с поддержкой OpenVPN, WireGuard, QUIC и uTLS. Серверный установщик закрепляет sing-box 1.14.4, для экспериментального CONNECT-IP — 1.15.0-alpha.13. Для Shadowsocks через WebSocket с TLS используется Xray 26.11.9. CONNECT-UDP реализован на Python через HTTP/1.1 Upgrade и капсулы DATAGRAM. Firefox, OpenSSH, AmneziaWG, Tailscale и Psiphon Tunnel Core используются для одноимённых профилей. Windows-движки устанавливаются отдельно. [sing-box](https://github.com/SagerNet/sing-box/releases) · [Xray](https://github.com/XTLS/Xray-core/releases) · [Tailscale](https://tailscale.com/download/windows)

Вкладка **Mesh** показывает устройства, проверяет фактический путь и переключает системный выход. Управляемые Linux-узлы могут объявлять роли exit node или peer relay. Одобрение выхода и разрешение relay задаются в политике вашей сети. [Выходные узлы](https://tailscale.com/docs/features/exit-nodes) · [Peer relay](https://tailscale.com/docs/features/peer-relay)

## Встроенная документация

Вкладка **Справка** содержит описание каждой стратегии, всех экранов, параметров узлов, импорта сертификатов, синхронизации ключей, проверок и типовых ошибок. Поиск работает без сети. Кнопка **Справка по профилю** открывает статью выбранной стратегии. Секреты профилей хранятся в %LOCALAPPDATA%\FLURUX под защитой Windows DPAPI.

## Сборка пакета безопасности

Откройте x64 Native Tools Command Prompt для Visual Studio 2022 с Windows SDK. Выполните следующие команды из корня проекта. Для упаковки требуется 64-разрядный Python 3.12 с модулем msilib. Приложение поддерживает Python 3.12 и новее.

```bat
security\Build-Guard.cmd
py -3.12 security\build_msi.py security\build\FluruxGuard.exe FLURUX-Security-x64.msi
```

Сборщик включает в MSI собственный помощник, GUI, инструкции и манифест проверяемых файлов. Он привязывает установленную копию приложения к SHA-256 собранного помощника. Внешние сетевые движки получают отдельно у разработчиков. Для публикации готового выпуска приложите ZIP, MSI и SHA256SUMS.txt. Текст релиза находится в releases/v0.3.0.md.

## Сборка EXE

В x64 Native Tools Command Prompt для Visual Studio 2022 выполните команды из корня проекта. Сборке нужен 64-разрядный CPython 3.12 с Tcl/Tk. Скачайте архив CPython для включения в EXE. Сборщик проверит его SHA-256 перед распаковкой. [CPython 3.12.16 x64, сборка Astral 20261123](https://github.com/astral-sh/python-build-standalone/releases/download/20261123/cpython-3.12.16%2B20261123-x86_64-pc-windows-msvc-install_only.tar.gz)

```bat
security\Build-Guard.cmd
py -3.12 packaging\build_setup.py security\build\FluruxGuard.exe cpython-3.12.16+20261123-x86_64-pc-windows-msvc-install_only.tar.gz release-assets\v0.3.3\FLURUX-0.3.3-Setup-x64.exe
```
